# Masha Home

Masha Home — личный проект по созданию персонального AI-помощника и цифрового пространства для совместной работы.

## Идея

Проект создаётся как эксперимент на стыке AI, автоматизации, памяти и человеческого взаимодействия.

Главная идея — не просто сделать чат-бота, а постепенно создать систему, которая умеет:

- помнить важный контекст;
- помогать с задачами и проектами;
- отслеживать договорённости;
- поддерживать рабочие процессы;
- автоматизировать рутинные действия;
- помогать учиться и развиваться;
- сохранять индивидуальный стиль общения;
- быть полезным партнёром, а не просто генератором ответов.



## Текущий этап

MVP:

- базовая структура проекта;
- документация;
- валидируемая Memory v0.4;
- локальное SQLite-хранилище с импортом/экспортом и backup, пока без переключения рабочего JSON;
- следующие этапы: Identity Kernel и нейтральный Model Provider.

## Архитектура

Проект развивается поэтапно:

`AI → Memory → Tasks → Automation → Integrations → Agents`

Архитектура будет уточняться по мере появления работающих компонентов.

## Статус

🚧 Проект находится в активной разработке.

Это экспериментальный проект, который постепенно превращается в рабочую систему.
