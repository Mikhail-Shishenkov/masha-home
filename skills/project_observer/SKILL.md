# Project Observer

Project Observer — первый реальный локальный навык Маши. Он позволяет безопасно
посмотреть ограниченную часть явно заданного workspace, не меняя проект.

Разрешённые операции:

- показать ограниченное дерево файлов;
- прочитать ограниченный UTF-8 текст из allowlist форматов;
- показать тип, размер и SHA-256 разрешённого файла.

Навык не имеет доступа к `local-data`, `.git`, виртуальному окружению, секретным
файлам и символическим ссылкам. Он не пишет файлы, не запускает процессы, не
использует сеть и не импортируется автоматически из manifest. Конкретный Tool
Adapter подключается только кодом приложения и проходит Skill Registry, Action
Autonomy Policy, bounded Agent Loop и deterministic verification.
