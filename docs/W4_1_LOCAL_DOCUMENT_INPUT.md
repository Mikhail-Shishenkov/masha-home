# W4.1 — Local Document Input

W4.1 adds one local source adapter to the existing source-neutral Document
Reader. It reads one PDF that Misha explicitly chooses in the native Qt file
picker and supplies bounded document evidence to one conversation turn.

## Authority and privacy

- The native `QFileDialog` selection is the only filesystem authority.
- A path typed in conversation, supplied by the renderer, or generated by a
  model has no authority and cannot cause a file read.
- The renderer receives only an opaque one-shot token, basename and byte size.
  It never receives a path, directory, raw bytes or local URI.
- The selected path exists only while the adapter validates and bounded-reads
  it. It is immediately discarded after bytes are staged in memory.

## Staging lifecycle

Only one PDF is staged per desktop bridge/composer. Selecting another replaces
it; clearing it, opening another conversation, starting a new one or closing
the Home clears it. Sending consumes the token before parsing, so tokens cannot
be reused. Nothing from staging is persisted.

The adapter rejects directories, symbolic links and oversized files. It checks
metadata before opening the file and reads at most 10 MiB + 1 byte to defend
against a size race. The existing `DocumentReader` remains the only PDF parser
and retains all W4 PDF/resource limits.

## Conversation and receipts

The current turn receives the same bounded, untrusted document-evidence
contract as W4. The main model remains `LOCAL_ONLY` with tools disabled. Local
document turns do not call Web Search or Web Fetch, work with Internet access
off, and never create a passive-memory candidate automatically.

A completed local read saves the normal bounded `DocumentReadReceipt` with
`source_kind=local`, basename, opaque source reference and no source domain.
It can render after restart, but bytes and path are gone and there is no local
"Open file" action. Past receipts are provenance/UI only: W4.1 deliberately
does not provide multi-turn document continuity.

## Manual acceptance

1. Add PDF → see `report.pdf · 1.8 MB`; ask “Маш, прочитай этот PDF и расскажи,
   о чём он.” Expect a grounded answer and `Прочитала PDF · … стр. · report.pdf`.
2. Attach a multi-page PDF and ask “Что написано на второй странице?” Expect a
   page-aware answer.
3. Cancel picker: no attachment and no turn. Remove the chip: the next turn is
   ordinary text-only conversation.
4. Oversized PDF: controlled failure, no model call. Fake `.pdf`: controlled
   PDF unreadable failure.
5. With Internet OFF, a selected local PDF still works. Typing a filesystem
   path without using the picker never reads it.

Not included: drag and drop, HTML file inputs, folder selection, file watching,
OCR, local-file navigation, local open-after-restart, or automatic document
continuity.
