# UI-04D Visual Composition Prototype

Disposable local prototype for evaluating the approved A + elements B/C visual
direction. It does not call Masha Home runtime, LLM, persistence or the network.

Open `index.html` directly in a desktop browser. No web server or dependency
installation is required.

Controls:

- `Left` / `Right` or `Space`: change scenario;
- `1`–`8`: select a scenario directly;
- `H`: hide all prototype captions and controls;
- `F`: enter/leave fullscreen;
- resize the window below 760 px to inspect the narrow desktop composition.

The eight deterministic visual fixtures are:

1. Idle;
2. Conversation;
3. Deep Conversation;
4. Activity;
5. Confirmation;
6. Check-in;
7. Emergency Stop;
8. Special Evening.

All raster scenes and this browser adapter are disposable. They do not select a
production frontend or final Visual Identity asset pack.
